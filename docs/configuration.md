# Конфигурация

Переменные окружения сервиса. Задаются в `.env` (dev, см. [`.env.example`](../.env.example))
или в `.env.production` (prod, см. [`.env.production.example`](../.env.production.example)).

Все переменные читаются централизованно в [`src/shared/config.ts`](../src/shared/config.ts)
(значения по умолчанию + чтение env). Остальной код импортирует константы оттуда,
а не дублирует строки/числа.

## Переменные приложения

| Переменная              | Описание                                                                                                                                                | По умолчанию |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| `DATABASE_URL`          | Строка подключения к PostgreSQL                                                                                                                         | —            |
| `ACCESS_KEY`            | Ключ доступа для входа (только первый запуск: хешируется в БД, затем удаляется из `.env`). Не используйте `$` — dotenv интерполирует его как переменную | —            |
| `ALLOWED_ORIGINS`       | Разрешённые Origin для OTLP-приёма (через запятую)                                                                                                      | —            |
| `SESSION_COOKIE_NAME`   | Имя cookie сессии                                                                                                                                       | `session_id` |
| `SESSION_TTL_DAYS`      | Срок жизни сессии в днях                                                                                                                                | `30`         |
| `MAX_BODY_BYTES`        | Максимальный размер тела запроса приёма (байт)                                                                                                          | `1048576`    |
| `MAX_LOGS_PER_BATCH`    | Максимум записей/спанов в одном батче                                                                                                                   | `200`        |
| `MAX_ADDITIONALS_BYTES` | Максимальный размер `attributes` одной записи (байт)                                                                                                    | `65536`      |
| `MAX_ADDITIONALS_DEPTH` | Максимальная глубина вложенности `attributes`                                                                                                           | `8`          |

## Переменные продакшен-окружения

Используются только в `docker-compose.prod.yml` (см. [`docs/deployment.md`](deployment.md)):

| Переменная          | Описание                                                                                  | По умолчанию |
| ------------------- | ----------------------------------------------------------------------------------------- | ------------ |
| `DOMAIN`            | Домен сервиса. Пусто → доступ по IP (HTTP, без TLS); задан → HTTPS (TLS-сертификат Caddy) | пусто        |
| `POSTGRES_PASSWORD` | Пароль пользователя БД `logscope` (вместо захардкоженного в dev-compose)                  | —            |

## Примечания

- `ACCESS_KEY` используется только при первом запуске (когда в БД нет
  пользователей): ключ хешируется (bcrypt), создаётся пользователь в таблице
  `users`, и `ACCESS_KEY` удаляется из `.env`. В БД хранится только хеш ключа
  (`access_key_hash`), сам ключ не хранится.
- `ALLOWED_ORIGINS` — список hosts (через запятую), с которых принимается
  OTLP-приём. Проверяется заголовок `Origin`/`Referer`; иначе `403`.
